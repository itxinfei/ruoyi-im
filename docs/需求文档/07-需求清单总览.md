## 四、核心业务规则（C-Series）

### 4.1 消息规则

| 编号 | 规则 | 确认结论 |
|------|------|---------|
| C-001 | 消息编辑时限 | 发送后 **5 分钟**内允许编辑 |
| C-002 | 已读回执开关 | 单聊可关闭；群聊**强制开启** |
| C-003 | 未读清零规则 | 用户可选：进入即清零 **或** 已读回执清零 |
| C-004 | 语音消息规格 | 最大时长 **60 秒**；支持语音转文字 |
| C-005 | 群详情入口 | 统一使用**右侧抽屉**（GroupDetailDrawer） |
| C-006 | 群管理员权限 | 修改群名、编辑公告、禁言、移除成员 |
| C-007 | 消息撤回时限 | 发送后 **2 分钟**内允许撤回 |
| C-008 | 文件上传限制 | 单文件最大 **100MB**；支持拖拽与粘贴 |
| C-009 | 通话重连 | 断线 **3 秒**内自动重连 |
| C-010 | DING 限额 | 每人每天最多发送 **10 条** DING |

### 4.2 权限规则

| 编号 | 规则 | 确认结论 |
|------|------|---------|
| C-011 | 数据可见性 | 普通用户**禁止**调用 admin 命名空间任何 API |
| C-012 | 管理员审计 | 管理员操作必须记录到审计表（im_audit_log） |
| C-013 | 离职处理 | 封禁 → 断开 WS → 移除所有群 → 自动转让群主 |
| C-014 | 权限校验 | 所有接口必须 RBAC 校验，禁止"能访问就能改" |

### 4.3 UI 规则

| 编号 | 规则 | 确认结论 |
|------|------|---------|
| C-015 | UI 交互基准 | 严格遵循**钉钉 Windows 8.2.0** |
| C-016 | 资源气密性 | 禁止外部 CDN，图标/字体/图片全部本地化 |
| C-017 | 导航完整性 | 左侧展示的每个一级模块必须有真实可用页面 |

### 4.4 技术规则

| 编号 | 规则 | 确认结论 |
|------|------|---------|
| C-018 | 并发上限 | 单会话支持 **≥ 500 人**并发 |
| C-019 | 消息延迟 | 消息 **≤ 300ms**送达，WS 心跳保持连接 |
| C-020 | JWT 安全 | Token 周期 **2h**（短），Renew 周期 **7d**（长） |

## 五、用户旅程验收清单

| 旅程 | 步骤数要求 | 成功标准 |
|------|-----------|---------|
| 新用户首次登录 | ≤ 5 步 | 1.登录 → 2.通讯录 → 3.展开部门 → 4.发消息 → 5.发送 |
| 日常沟通 | 即时 | 收到通知 → 点击会话 → 查看 → 回复 → 状态=已发送 |
| 群组协作 | ≤ 3 步 | 1.建群 → 2.选成员 → 3.设群名 |
| 消息搜索 | 即时 | 搜索响应 ≤ 500ms，结果可跳转 |
| 文件协作 | 即时 | 上传成功率 ≥ 99%，进度可见 |
