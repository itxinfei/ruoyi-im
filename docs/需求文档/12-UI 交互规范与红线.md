## 八、消息气泡交互红线

### 8.1 精准红线

| 项 | 规范 | 禁止 |
|----|------|------|
| 发送方气泡背景 | `#277EFB`（品牌蓝） | ❌ 使用其他蓝 |
| 接收方气泡背景 | `#FFFFFF` + 边框 | ❌ 灰色/渐变背景 |
| 气泡圆角 | `8px 4px 8px 8px`（发送方右上尖角） / `4px 8px 8px 8px`（接收方左上尖角） | ❌ 统一 12px 圆角 |
| DING 消息/系统消息 | DING 四向对称 `var(--dt-radius-lg)` 8px / 系统消息无气泡 | ❌ 统一处理 |

```scss
/* 发送方：右上 4px 尖角，其余 8px */
.is-own .chat-bubble {
  border-radius: 8px 4px 8px 8px;
}
/* 接收方：左上 4px 尖角，其余 8px */
.chat-bubble:not(.is-own) {
  border-radius: 4px 8px 8px 8px;
}
/* DING 通知消息不区分收发，对称圆角 */
.ding-bubble {
  border-radius: var(--dt-radius-lg);  /* 8px */
}
/* 系统消息无气泡，居中灰条 */
.system-message {
  background: transparent;
  text-align: center;
  color: var(--dt-text-tertiary);
  font-size: 12px;
  padding: 4px 0;
}
```

| 消息最大宽度 | 聊天区宽度的 70% | ❌ 超出 |
| 内侧间距 | 同侧 4px，异侧 16px | ❌ 不一致 |
| 已读回执位置 | 发送方气泡左下角，距边缘 4px | ❌ 放在气泡内 |
| 操作工具条 | Hover 浮现，距气泡 8px | ❌ 常驻显示 |
| 聊天区背景 | `var(--dt-bg-chat)` (#f5f6f7) | ❌ 白色 |

### 8.2 附件消息视觉

| 类型 | 视觉 | 交互 |
|------|------|------|
| 图片 | 圆角矩形缩略图（120~200px） | 点击 HD 预览，查看原图需二次操作 |
| 文件 | 文件名 + 大小 + 类型图标 | 点击下载，右键更多 |
| 语音 | 波形条 + 时长 | 点击播放/暂停，右键转文字 |
| 视频 | 播放器封面 + 播放图标 | 点击全屏播放 |

### 8.3 撤回与重新编辑

| 场景 | 字号 | 颜色 | 对齐 | 附加内容 |
|------|------|------|------|---------|
| 自己撤回文本/链接消息 | 12px | `var(--dt-text-tertiary)` (#8A9099) | 居中 | \"+重新编辑\"链接（品牌蓝 `#277EFB`），点击回填输入栏 |
| 自己撤回媒体消息（图片/文件/语音） | 12px | `var(--dt-text-tertiary)` | 居中 | 无重新编辑链接 |
| 群主/管理员撤回他人消息 | 12px | `var(--dt-text-tertiary)` | 居中 | 显示\"群主 撤回了 张三 的一条消息\" |
| 他人自行撤回 | 12px | `var(--dt-text-tertiary)` | 居中 | 显示\"张三 撤回了一条消息\"（仅群聊） |

**实现约束**

- 撤回时限 **2 分钟**（超时操作按钮灰显）
- 重新编辑窗口 **5 分钟**（仅文本/链接类消息显示链接）
- 撤回**无需**二次确认弹窗，直接执行
- 撤回后**不显示**原始气泡，整条替换为居中灰色提示文字
- 仅发送者本人可见\"重新编辑\"链接

```scss
.message-recall {
  display: flex;
  align-items: center;
  justify-content: center;
  gap: var(--dt-spacing-sm);
  padding: var(--dt-spacing-sm) 0;
  font-size: 12px;
  color: var(--dt-text-tertiary);
  user-select: none;

  .recall-edit-link {
    color: var(--dt-brand-color);
    cursor: pointer;
    &:hover { color: var(--dt-brand-hover); text-decoration: underline; }
  }
}
```

## 十二、通用组件红线

> 所有组件必须具备 6+1 状态：默认 / Hover / Active / Selected / Disabled / Loading / Empty / Error

### 12.1 必须统一的组件

1. **一级导航项**：图标尺寸、选中态、hover 态、底部头像区风格一致
2. **列表项**：高度 56px、左右 padding 16px、标题/摘要层级、未读/状态标签一致
3. **工具栏**：按钮 32×32、图标 16px、hover 浅底
4. **抽屉/弹窗**：标题 16px 加粗、操作区位于底部右侧、关闭逻辑统一
5. **空状态**：64px 图标 + 14px 文案 + 16px 间距

### 12.2 导航项规范（.nav-item）

| 项 | 值 |
|----|----|
| flex 方向 | row（图标在前，文字在后） |
| 高度 | 40px |
| 图标大小 | 16px |
| 文字大小 | 14px |
| 图标文字距 | 12px |
| 激活态背景 | `var(--dt-bg-session-active)` |

## 十四、禁止行为汇总（一票否决）

### 14.1 视觉禁区（出现即驳回）

- ❌ 复杂阴影 / 渐变背景 / CSS 动画 / filter 模糊 / backdrop-filter / 悬浮位移缩放
- ❌ 圆角 8px 以上（消息气泡 12px 除外）
- ❌ 非标准蓝（非 `#277EFB`）
- ❌ 硬编码颜色值（必须走 CSS 变量）
- ❌ 非栅格间距（7/10/13/14/15/17/18/20/22/25/30px）
- ❌ 头像搞圆形（桌面端是 4px 圆角方形）
- ❌ 侧边栏用深灰底或蓝色渐变（必须是品牌蓝 #277EFB 纯色底 + 白色图标）

### 14.2 交互禁区

- ❌ 死按钮（点击无任何反馈）
- ❌ 假菜单（展开后无可用项）
- ❌ 空白承接页（"开发中"占位）
- ❌ 右侧常驻详情列（必须用抽屉）

### 14.3 结构禁区

- ❌ L2 响应式折叠为移动端抽屉（桌面端稳定三栏）
- ❌ 卡片化聊天区（消息必须是气泡流）
- ❌ 一页一套按钮风格

### 14.4 资源禁区

- ❌ 外部 CDN 引用
- ❌ 网络字体
- ❌ 渐变背景大图

## 十五、验收自检流程

| 阶段 | 检查项 | 通过条件 |
|------|--------|---------|
| 1. 骨架检查 | L1/L2/L3 宽度、高度符合§1、§2 | 全部在允许范围 |

| 4. 状态检查 | hover/active/disabled 态齐全 | 6+1 态覆盖 |
| 5. 交互检查 | 所有按钮/入口真实可用 | 无死路 |
| 6. 一致性检查 | 导航/列表/工具条风格一致 | 全局无例外 |
| 7. 资源检查 | 无外网依赖 | 全部本地化 |
