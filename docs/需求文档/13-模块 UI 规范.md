# 13-模块 UI 规范

> **定位**：除 IM 聊天主链路外，各功能模块的**页面级 UI 规范**。
> **上游**：`11-UI 设计总纲与视觉规范`（原则 / 模板库）→ `12-UI 交互规范与红线`（像素级权威值）
> **复刻基准**：钉钉 Windows 8.2.0 桌面端。复刻等级 L1–L4、各类页面最低等级、不照搬清单、尺寸冲突裁决均见 `11-UI 设计总纲与视觉规范.md`「复刻基准声明」（SSOT，本文不重复）。
> **本文职责**：只定义**模块特有的布局、组件、状态与验收点**；通用像素值、色值、间距一律以 `12` 为准，本文不重复、不覆盖。
> **Token 源**：`ruoyi-im-web/src/styles/design-tokens.scss`
> **更新时间**：2026-10-28

### 1.2 每个模块的六段式结构

所有模块规范统一按以下六段编写，**缺一段视为未完成**：

1. **页面定位与模板**：模块 ID、模板类型、主要任务
2. **空间布局**：L1/L2/L3/Overlay 划分与关键尺寸
3. **组件级规范**：模块特有组件（列表行、卡片、表单项…）
4. **状态清单**：必须覆盖 **6+1 态**（默认 / Hover / Active / Disabled / Loading / Empty / Error）
5. **交互路径**：主路径 + 异常路径 + 返回路径
6. **验收点（AC）**：可勾选、可检查的条目

### 1.3 ⚠️ L2 宽度裁决（冲突解决）

历史素材中同一模块的 L2 宽度存在矛盾（通讯录曾写 `250px`、收藏/邮箱曾写 `200px`、待办现统一为 `240px`、`12` 统一写 `240px`）。**以本文为准**：

| L2 类型 | 宽度 | 适用模块 | 说明 |
|---------|------|---------|------|
| **会话列表** | **250px** | 消息 | `12` §一 已定，唯一例外 |
| **模块主侧栏** | **240px** | 通讯录、云盘、审批、待办、工作台、搜索、AI | 承载目录树 / 分类 / 筛选 |
| **分类导航** | **200px** | 收藏、邮箱 | 仅承载分类枚举，不承载目录树 |

> ❌ 历史素材中的「通讯录 250px」作废，统一 **240px**。

### 1.4 ⚠️ 间距违规修正

历史素材中收藏 / 待办的「右侧内容区 `padding: 20px`」违反 `12` §四 8px 栅格（20px 属禁止值）。

> ✅ 统一修正为 **`padding: 24px`**。

### 1.5 ⚠️ 特例白名单：全屏协作（通话）场景

`12` §十四 禁止渐变背景、`transform` 缩放位移、圆形头像。**通话属于「全屏协作」沉浸场景，钉钉原版即为深色 + 渐变 + 正圆控件**，故在该场景下列为**白名单豁免**：

| 禁止项（`12`） | 通话场景豁免 | 边界 |
|---------------|-------------|------|
| 渐变背景 | ✅ 允许 | 仅用于来电弹窗、控制栏上下渐变遮罩 |
| `transform` 缩放 | ✅ 允许 | 仅用于通话控制按钮 hover（1.05）与按下（0.9） |
| 圆形（50%） | ✅ 允许 | 仅用于通话控制按钮、语音通话中央头像 |

> ❌ 豁免**不延伸至**业务页面：工作台卡片、应用图标、列表头像仍严格禁止渐变与位移。

### 1.6 跨模块必须复用的组件

| 组件 | 复用要求 |
|------|---------|
| 列表行 | 高度 **56px**、左右 padding **16px**、头像 36×36 圆角 4px（**会话列表头像 40×40**，见 `11` 裁决表） |
| 分类导航项 | 高度 **40px**、圆角 4px、图标 16px、图标文字间距 8px；选中态 `#E6F2FF` 底 + 左侧 3px 品牌蓝竖条 |
| 工具栏 | 高度 **48px**，按钮 32×32，图标 16px |
| 详情抽屉 | 从右侧滑出，宽 **320px**（群详情 520px），0.3s 缓动 |
| 空状态 | 64px 图标 + 14px 文案 + 16px 间距，图标色 `--dt-text-quaternary` |
| 骨架屏 | 占位底色用 `--dt-bg-hover` / `--dt-border-light`，**不新增专用 token** |

## 二、通讯录（contacts）

### 2.1 定位与模板

- **模板**：列表-详情协同（`L1 + L2 + L3 + Drawer`）
- **任务**：浏览组织架构树 / 搜索联系人与群组 / 查看详情并发起聊天 / 管理好友关系

### 2.2 空间布局

| 区域 | 宽度 | 内容 |
|------|------|------|
| L2 目录侧栏 | **240px** | 搜索框（32px 高，底 `rgba(23,26,29,0.04)`）+ Tab（组织架构 / 我的群组 / 我的好友 / 外部联系人） |
| L3 主视图 | flex:1 | 当前选中节点的成员列表 |
| Drawer | 320px | 成员 / 群组详情 |

- **Tab 样式**：文字行高 40px，激活项带 **2px 品牌蓝下划线**
- **面包屑**：L3 顶部显示「总公司 / 技术部」层级路径

### 2.3 组件级规范

**组织架构树**
- 行高 `36px`；每层级缩进 `16px`
- 部门图标 `Folder`，色 `--dt-text-icon`；展开箭头顺时针旋转 90deg
- Hover `var(--dt-bg-hover)`；选中 `var(--dt-bg-session-active)` + 文字加粗

**成员列表**
- 表头 40px，底 `--dt-bg-body`，列：姓名 / 职位 / 部门 / 手机号
- 行高 `56px`；头像 36×36 圆角 4px；姓名 14px Primary，职位 12px Secondary
- 右侧「发消息」按钮**默认隐藏，Hover 出现**

**联系人详情卡片**
- 头部：品牌浅蓝底，头像 64px 居中，姓名 18px 加粗
- 信息块：部门 / 职位 / 手机 / 邮箱 / 工号；Label 12px Tertiary，Value 14px Primary 且**支持一键复制**
- 底部操作栏：`[发消息]` 主按钮（品牌蓝）、`[视频通话]` `[语音通话]` 次按钮（线性边框）

### 2.4 状态清单

| 状态 | 表现 |
|------|------|
| Loading | 树用骨架屏，列表用顶部进度条 |
| Empty | 「未找到匹配的联系人」+「清除搜索」按钮 |
| Selected | 树节点 `--dt-bg-session-active`，右侧高亮并显示所属部门路径 |
| Hover | 列表行出现「发消息」「收藏」快捷图标 |
| Error | 树加载失败显示重试入口 |

### 2.5 交互路径

1. 发起聊天：点击行 → 抽屉 → 发消息 → 跳转 `/chat?id=xxx` 并选中会话
2. 树联动：点击部门 → 列表刷新 → 面包屑更新
3. 全局搜索：输入关键词 → L2 切换为搜索结果视图 → 分类显示「联系人(3)/部门(0)/群组(1)」

### 2.6 验收点

- [ ] AC1 部门树支持无限级嵌套，展开/收起无卡顿
- [ ] AC2 成员列表支持 A-Z 排序与首字母导航
- [ ] AC3 抽屉点击遮罩或外部自动收起，动画平滑
- [ ] AC4 全部颜色 / 间距 100% 引用 token，无硬编码

## 三、工作台（workbench）

### 3.1 定位与模板

- **模板**：工作台聚合（`L1 + L2 + Main View`）
- **任务**：访问常用业务系统 / 查看个人办公概览 / 搜索与发现应用

### 3.2 空间布局

- **L2**：240px，三档导航（应用中心 / 我的应用 / 应用管理），底 `var(--dt-bg-body)`
- **L3**：flex:1，底 `var(--dt-bg-body)`；内容区**最大宽度 1100px**（大屏水平居中），上下 padding 24px、左右 32px
- **Banner**：高 **160px**，**纯品牌蓝单色**（`--dt-brand-color`），仅承载问候语 + 个人概览
- **分组区**：纵向排列，组标题带 **4px 品牌蓝竖线**指示器

### 3.3 组件级规范

**应用卡片**
- 栅格：`repeat(auto-fill, minmax(240px, 1fr))`，gap 16px，**最多 4 列**，不固定 5 列
- 卡片：底 `--dt-bg-card`，padding 16px，圆角 `--dt-radius-lg`
- 图标区 44×44，圆角 8px（**≤12px**），浅色业务底优先复用 `--dt-brand-bg`
- 文字：主标题 14px / 600 单行截断；描述 11px `--dt-text-quaternary`
- Hover：**仅**边框变品牌蓝 + `--dt-shadow-sm`；**严禁** translateY / scale / 渐变

**概览统计块**
- 内嵌于 Banner 右侧，**不使用悬浮窗或独立卡片**
- 半透明白底 `rgba(255,255,255,0.15)` + `1px solid rgba(255,255,255,0.2)`，圆角 `--dt-radius-lg`
- **严禁 `backdrop-filter`**（纯色叠加替代）
- 数字 22px / 700，文字 11px / opacity 0.8；两 stat 间 `1px×30px` 白色 0.2 竖线

**最近使用区**
- 固定高 92px，横向滚动，项间距 24px
- 图标容器 48×48，圆角 8px（**禁止 50% 圆形**）；文字 12px Secondary

**分组标题**：15px / 700，段间距 32px

### 3.4 状态清单

| 状态 | 表现 |
|------|------|
| Default | 白底 + 透明边框 |
| Hover | 边框品牌蓝 + 轻阴影，**无位移/缩放** |
| Active | 背景 `--dt-bg-hover`，100ms 内出现 |
| Loading | 骨架屏（120×76 占位 + 40×40 图标 + 120×14 文字） |
| Empty | 「暂无可用应用」，64px 图标 + 14px Tertiary 文字 |
| Disabled | `opacity: 0.5; cursor: not-allowed`，Hover Tooltip「暂无访问权限」 |
| Error | 卡片右上角红色感叹号 +「加载失败」，点击重试 |

### 3.5 交互路径

1. 应用启动：点击 → 内部应用路由跳转；外部应用受控 iframe 或新标签页
2. 搜索应用：`/` 聚焦 → 实时过滤（常用 > 名称 > 描述）
3. 自定义布局：`管理常用` → 编辑模式 → 卡片出现 `×` → 拖拽重排 → 退出自动保存

**键盘**：`/` 聚焦搜索、`Esc` 退出、`↑↓←→` 栅格移动焦点、`Enter` 启动、`Ctrl+E` 编辑模式

**拖拽反馈**：被拖卡片 `opacity: 0.5`，目标位置 2px 品牌蓝虚线，**禁用 ghost 模糊**

### 3.6 验收点

- [ ] AC1 栅格在 1280 / 1440 / 1920 三档自适应列数
- [ ] AC2 图标 Retina 清晰（SVG 或 3x）
- [ ] AC3 概览数据经 WebSocket 实时更新，无数据不显示空白卡
- [ ] AC4 Banner **绝对纯色**，无 `linear-gradient` / `radial-gradient`
- [ ] AC5 卡片 hover 无 `transform`
- [ ] AC6 统计块无 `backdrop-filter`
- [ ] AC7 Loading / Empty / Error 有完整占位，无白屏

## 四、云盘与文档（documents）

> **存储**：文件实体一律存 **MinIO**（见 `08` §四），库内只存引用；**在线编辑**由 **ONLYOFFICE Docs** 提供（见 `08` §七）。

### 4.1 定位与模板

- **模板**：列表-详情协同（`L1 + L2 + L3 + Toolbar`）
- **任务**：个人 / 部门文件管理、上传下载分享、**在线预览与 Office 在线编辑**、多级文件夹

### 4.2 空间布局

- **L2**：240px，固定筛选（全部 / 收藏 / 最近 / 回收站）+ 文件夹树
- **L3**：flex:1，文件列表或网格
- **Toolbar**：L3 顶部，高 **48px**，含上传 / 新建 / 视图切换 / 搜索

| 视图 | 卡片尺寸 | 适用 |
|------|---------|------|
| 列表 | 行高 48px | 大量文件管理 |
| 网格 | 120×160 | 图片 / 视频预览 |

### 4.3 组件级规范

**文件图标色**：PDF `--dt-file-pdf`、Word `--dt-file-word`、Excel `--dt-file-excel`、PPT `--dt-file-ppt`、其他 `--dt-file-other`

**列表行**
- Hover：整行 `var(--dt-bg-hover)`，右侧显示分享 / 收藏 / 删除
- 选中：`--dt-bg-session-active` + 左侧复选框

**传输管理器**（右下角悬浮或独立 Tab）
- 上传中：进度条 + 速度 + 剩余时间
- 失败：红色警告图标 + 重试
- 完成：自动消失或 Toast

**在线编辑入口（ONLYOFFICE）**
- 行 Hover 或右键菜单出现「在线编辑」项（docx/xlsx/pptx 及文本类可用，其余置灰）
- 点击后**全屏蒙层**承载 ONLYOFFICE 编辑器，顶部保留文件名 + 保存状态 + 关闭
- 编辑器内**不套用本项目 token**，但容器外壳（标题栏、遮罩）需遵循 `12`

### 4.4 状态清单

| 状态 | 表现 |
|------|------|
| Uploading | 行背景微弱扫描动效 + 实时百分比 |
| Empty | 「将文件拖拽至此上传」，点击中央大图标触发 |
| Previewing | 全屏蒙层，支持缩放 / 旋转 / 下载 |
| Drag & Drop | 主区边缘蓝色虚线边框 +「松开上传」 |
| Editing | 顶部显示「XX 正在编辑」协同状态（多人时） |
| Error | 分片失败行标红，支持续传重试 |

### 4.5 交互路径

1. 上传：点击上传 → 系统选择器 → 右下角进度框（>100MB 自动分片）
2. 右键菜单：预览 / 下载 / 分享 / 重命名 / 移动 / 删除 / **在线编辑**
3. 面包屑：点击上级目录回退

### 4.6 验收点

- [ ] AC1 大文件（>100MB）分片上传进度实时反馈
- [ ] AC2 右键菜单在列表底部自动向上弹出，不溢出屏幕
- [ ] AC3 文件夹双击进入，文件单击选中 / 双击预览
- [ ] AC4 列表触底自动分页
- [ ] AC5 Office 文件在线编辑可正常打开并回写 MinIO，失败有明确错误提示

## 五、审批（approval）

### 5.1 定位与模板

- **模板**：列表-详情协同 + 表单页
- **任务**：处理待我审批 / 发起各类审批 / 查看进度与抄送

### 5.2 空间布局

- **L2**：240px，分类：待我审批 / 我发起的 / 抄送我的 / 已处理
- **L3**：单据列表 + 搜索 + 类型筛选 + 状态筛选
- **Drawer**：320px，点击列表项从右滑出审批详情

**详情抽屉**
- 头部：单据标题 + 状态标签（PENDING / APPROVED / REJECTED）
- 内容：表单数据 + 垂直流程时间轴
- 底部固定操作栏：同意 / 拒绝 / 转交 / 加签

### 5.3 组件级规范

**状态标签**

| 状态 | 配色 |
|------|------|
| 待审批 | `--dt-warning-color` 淡化底 + 橙字 |
| 已通过 | `--dt-success-color` 淡化底 + 绿字 |
| 已拒绝 | `--dt-error-color` 淡化底 + 红字 |
| 已撤销 | `--dt-text-tertiary` 淡化底 + 灰字 |

**流程时间轴**
- 已完成：实心绿圆 + 白色对号
- 进行中：空心蓝圆 + 旋转 Loading
- 未开始：空心灰圆
- 点击节点查看审批人意见与处理时间

**动态表单项**：行高 40px；Label 固定宽 **80px** 居右，Value 居左；多附件用缩略图列表，点击预览

### 5.4 状态清单

| 状态 | 表现 |
|------|------|
| Pending Action | 底部操作栏高亮 + 呼吸灯提示 |
| Success Feedback | 绿色 Toast，详情状态即时更新 |
| Form Validation | 必填缺失红边框 + 自动定位首个错误项 |
| Empty | 「暂无待处理审批」空状态插画 |
| Submitting | 按钮 Loading，防重复提交 |

### 5.5 交互路径

1. 发起申请：工作台点击「请假」→ 全屏表单 → 提交 → 跳转「我发起的」
2. 快捷审批：列表行 Hover 直接显示 同意/拒绝 小按钮（批量场景）
3. 多级联动：选择审批类型后表单字段动态刷新

### 5.6 验收点

- [ ] AC1 流程图能清晰表达并行审批与或签
- [ ] AC2 表单支持富文本、附件上传
- [ ] AC3 操作按钮点击后进入 Loading，防重复提交
- [ ] AC4 已处理单据支持打印 / 导出 PDF

- AI 端：`--dt-bg-card` 或 `--dt-brand-bg` + `1px solid var(--dt-border-light)`，**禁止新增紫色描边体系**
- 行高 **1.6**（长文本阅读）；流式输出末尾带闪烁 `|` 光标

**结构化响应**
- 代码块：`--dt-bg-card-dark` 或 `--dt-nav-sidebar-bg` 深底 + 点击复制
- Markdown 表格：全宽 + 斑马纹

**Prompt 快捷芯片**：胶囊型，圆角 `--dt-radius-full`，白底蓝边，如「✍️ 润色周报」「📊 数据分析」「🌐 中英翻译」

### 11.4 状态清单

| 状态 | 表现 |
|------|------|
| Thinking | AI 头像呼吸灯 + 输入区上方「AI 正在思考...」 |
| Streaming | 自动滚到底部，随时可「停止」 |
