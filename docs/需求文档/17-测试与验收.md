# 17 测试与验收

> 本文档规定 6 层测试策略和模块验收 Checklist。关联模块：07-需求清单总览.md。

## 一、测试 6 层金字塔

| 层级 | 范围 | 工具 | 覆盖率目标 |
|------|------|------|-----------|
| L1 单元测试 | Service / Util / 工具函数 | JUnit 5 + Mockito | ≥70% |
| L2 组件测试 | Vue 组件 (Panel/Dialog) | Vitest + Vue Test Utils | ≥60% |
| L3 集成测试 | Controller→Service→DB | Spring Boot Test | ≥50% |
| L4 接口契约测试 | REST API 签名 | Postman / Newman | 100% P0 接口 |
| L5 E2E 测试 | 核心业务流程 | Playwright | P0 场景 100% |
| L6 性能压力 | 并发/APM | JMeter / Gatling | WS 10K 并发 |

## 三、CI/CD 集成配置

```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Node
        uses: actions/setup-node@v3
        with:
          node-version: '20'
      - name: Install deps
        run: npm ci
      - name: Unit & Component Tests
        run: npm run test:ci   # vitest --coverage
      - name: E2E Tests
        run: npm run test:e2e   # playwright
      - name: Performance Test
        run: npm run test:perf   # k6 script
      - name: Security Scan
        run: npm run security:scan   # zap-cli
      - name: Upload Coverage
        uses: actions/upload-artifact@v3
        with:
          name: coverage-report
          path: coverage/
```

## 四、验收 Checklist（按模块）

### P0 消息模块
- [ ] 登录后会话列表加载 <2s
- [ ] 文本消息发送→接收端到端 <200ms
- [ ] 断线重连后离线消息补推完整
- [ ] 消息发送成功率 ≥99.9%

### P0 搜索
- [ ] 全局搜索响应 <500ms (95 分位)
- [ ] 联系人搜索匹配正确（姓名/拼音/手机号）

### P0 WS 连接
- [ ] JWT 过期后自动 refresh 重连
- [ ] 离线消息最大 10000 条 FIFO 丢弃
- [ ] WS 断线 15 次后切换 HTTP 轮询

### P1 通讯录
- [ ] 部门树加载正确
- [ ] 外部联系人 CRUD

### P1 DING
- [ ] 创建/提醒/确认/过期全链路

### P1 会话列表
- [ ] 进入消息页后默认展示会话列表
- [ ] 点击会话项后聊天区切换且当前选中态高亮
- [ ] 会话列表显示未读数，空状态展示提示
- [ ] 会话搜索可以过滤结果

### P1 聊天区与气泡
- [ ] 进入会话后滚到最后一条消息
- [ ] 发送方气泡在前、头像在后、最大宽度 70%
- [ ] 同侧间距 4px，异侧 16px
- [ ] 时间分割线不造成双重留白
- [ ] 引用/回复/转发菜单可进入实际流程

### P1 输入区
- [ ] Enter 发送，Ctrl+Enter 换行
- [ ] 图片/文件按钮可选本地文件并上传
- [ ] 粘贴图片/文件会触发上传
- [ ] 发送失败时提示并支持重试
- [ ] 群聊 `@` 可以选人

### P1 群详情与群文件
- [ ] 打开群详情可以看到名称、成员、公告
- [ ] 详情内有群文件入口，打开面板能加载文件列表
- [ ] 文件可按类别筛选，支持上传与下载

### P1 通话
- [ ] 聊天头部语音/视频按钮可发起通话
- [ ] 对端可接听、拒绝、挂断，异常有提示
- [ ] 通话状态流（calling/connecting/talking/ended）可切换

## 六、测试环境与数据

- **独立测试库**：使用 Docker Compose 启动 MySQL、Redis、MinIO 等，避免污染生产数据
- **测试账号**：统一在 `test-data/users.json` 中维护，包含普通用户、管理员、群主等角色
- **Mock 数据**：对外部服务（文件存储、语音转写）使用本地 Mock Server，确保 CI 可离线运行

## 七、回归与风险管理

- 每次功能交付后必须在 `03-实现状态矩阵.md` 记录 `✅ 冒烟 + ✅ 功能回归`
- 高风险功能（通话、语音、文件）需额外编写 **失败场景** 用例（网络中断、权限错误、文件大小超限）
- 若出现 **测试阻塞**（依赖服务不可用），需在 PR 评论或 issue tracker 标记并提供临时方案
