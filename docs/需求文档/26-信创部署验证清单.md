# 26 信创部署验证清单

> **定位**：国产化 Linux（UOS / 麒麟 / Deepin）上的部署与验证步骤。
> **前置**：`16-部署与环境搭建.md`、`20-技术栈最终定版.md`
> **目标**：拿到一台信创机器后，**按顺序执行**即可出活。

## 一、支持的国产化平台

| 系统 | 内核 | Electron 兼容 | WS 兼容 | WebRTC 兼容 | 状态 |
|------|------|-------------|---------|-------------|------|
| **统信 UOS 桌面版** | Debian 系 | ✅ | ✅ | ✅ | ✅ 已验证 |
| **麒麟 Kylin 桌面版** | Ubuntu/CentOS 系 | ✅ | ✅ | ✅ | ✅ 已验证 |
| **Deepin** | Debian 系 | ✅ | ✅ | ✅ | ✅ 已验证 |
| **欧拉 openEuler** | CentOS 系 | ✅ | ✅ | ✅ | ✅ 可运行 |
| **麒麟信安** (服务器) | 自研内核 | ⚠️ 需打 patch | ✅ | ⚠️ 需验证 | ⚠️ 待确认 |

> **关键**：Electron 内置 Chromium，**不依赖系统 WebView**，是信创兼容最稳桌面方案。Tauri（依赖系统 WebView）在信创风险高。

## 二、前置环境要求

### 2.1 最低硬件

| 资源 | 要求 |
|------|------|
| CPU | 4 核（x86_64 或 aarch64 均支持）|
| 内存 | 8GB（推荐 16GB，因 Electron + Docker 多容器）|
| 磁盘 | 系统盘 40GB + 数据盘 100GB（消息附件增长快）|
| 网络 | 内网互通，**不要求外网** |

### 2.2 软件依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| Docker | 24.x+ | 容器运行时 |
| Docker Compose | v2.x | 编排 |
| Nginx | 1.24+ | 反向代理（系统自带或手动装）|
| Fontconfig | 任意 | 中文字体渲染 |
| 中文字体 | WenQuanYi / Noto Sans CJK | Electron 渲染中文必需 |
| PulseAudio | 任意 | 音视频通话（可选，无音频则不装）|

## 三、部署步骤（按顺序，禁止跳步）

### Step 1：安装 Docker & Docker Compose

```bash
# 信创系统上安装 Docker（以 UOS 为例）
sudo apt update
sudo apt install -y docker.io docker-compose-plugin

# 验证
docker --version
docker compose version

# 启动并自启
sudo systemctl enable --now docker
```

### Step 2：安装中文字体（Electron 中文乱码必需）

```bash
sudo apt install -y fonts-wqy-zenhei fonts-noto-cjk
# 刷新字体缓存
fc-cache -fv
fc-list :lang=zh | head -3   # 验证至少有一个中文字体
```

### Step 3：下载部署包

```bash
# 在内网 SCM 或文件服务器上下载
wget http://internal-scm/releases/ruoyi-im-latest.tar.gz
tar -xzf ruoyi-im-latest.tar.gz
cd ruoyi-im/
```

### Step 4：配置 `.env`（关键安全项）

```env
# .env（不要提交到 Git）
JWT_SECRET=<至少32字符的随机字符串，用 openssl rand -base64 48>
MYSQL_ROOT_PASSWORD=<MySQL root 密码>
MYSQL_PASSWORD=<业务用户密码>
MINIO_ROOT_USER=admin
MINIO_ROOT_PASSWORD=<至少8字符>
MINIO_BUCKET=im-assets
REDIS_PASSWORD=<Redis 密码>
ONLYOFFICE_JWT_SECRET=<ONLYOFFICE 内部鉴权密钥>
```

### Step 5：启动全部服务

```bash
docker compose up -d
# 预期 8 个容器全部 Up
docker compose ps
```

### Step 6：初始化数据库

```bash
# SQL 脚本在 ruoyi-im/sql/im.sql
docker compose exec -T mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" < sql/im.sql
```

### Step 7：验证

```bash
# 后端健康检查
curl -s http://localhost:8080/im/health | jq .
# 期望：{"code":200,"msg":"UP"}

# 前端静态资源
curl -s -o /dev/null -w "%{http_code}" http://localhost:80/
# 期望：200

# WebSocket 连接（需要登录后测试）
# 打开浏览器登录，F12 Network → WS → 应看到 ws://localhost/im/ws 连接成功

# Docker 全部正常
docker compose logs --tail=20
# 无 ERROR 或异常
```

## 六、故障排查速查

| 现象 | 排查 | 解决 |
|------|------|------|
| Electron 白屏 | 检查 `base: './'` 配置 + dist/assets 路径 | 重新 `vite build --mode electron` |
| 中文乱码 | `fc-list :lang=zh` | 装中文字体 + `fc-cache -fv` |
| WS 连接失败 | Nginx 配置 `proxy_set_header Upgrade $http_upgrade` | 补 Nginx WS 代理配置 |
| 验证码不显示 | 检查 `/im/auth/captcha` 是否 200 | 后端启动时加载字体 |
| 消息乱序 | 检查是否按 `serverSequence` 排序 | 前端 store 排序逻辑 |
| 音视频不通 | LiveKit 容器日志 + TURN 状态 | coturn 日志 / 端口 |
| 文档打不开 | ONLYOFFICE JWT 签名是否正确 | 检查 `ONLYOFFICE_JWT_SECRET` 一致性 |
| 安装包无签名告警 | Windows SmartScreen 拦截 | 加 EV 代码签名或内网 CA + 组策略 |
| Deepin 字体发虚 | `qt5ct` 或 Electron `disable-gpu` | `--disable-gpu` 启动参数 |
