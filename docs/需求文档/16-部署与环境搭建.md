### 1.3 启动顺序

```text
1. Docker 基础设施 (MySQL/Redis/RabbitMQ/MinIO)
2. Nacos (注册中心 + 配置中心)
3. 后端微服务 (im-auth → im-message → im-group → im-call → ...)
4. 前端 npm run dev (端口 5173)
```

## 二、生产部署规格

### 2.1 服务器最低/推荐配置

| 部署模式 | CPU | 内存 | 磁盘 | 并发用户 |
|---------|-----|------|------|---------|
| 单机部署（开发/测试） | 2 核 | 4 GB | 50 GB SSD | <100 |
| 最小集群（500 人） | 8 核 × 1 | 16 GB × 1 | 200 GB SSD | 500 |
| 中型集群（5000 人） | 8 核 × 12 | 16 GB × 12 | 1 TB SSD | 5000 |
| 大型集群（50000+） | 16 核 × 24 | 32 GB × 24 | 5 TB 分布式存储 | 50000+ |

### 2.2 端口映射

| 端口 | 组件 | 协议 |
|------|------|------|
| 80/443 | Nginx (LB) | HTTP/HTTPS |
| 8848 | Nacos | HTTP |
| 3306 | MySQL | TCP |
| 6379 | Redis | TCP |
| 5672 | RabbitMQ | AMQP |
| 15672 | RabbitMQ Mgmt | HTTP |
| 9000 | MinIO | HTTP |
| 7800 | LiveKit | WebRTC |
| 8080-8092 | im-* 微服务 | HTTP |
| 8080 | Gateway | HTTP |

### 2.3 JVM 生产参数模板

```bash
JAVA_OPTS="-Xms1g -Xmx2g -XX:+UseG1GC -XX:MaxGCPauseMillis=200 -XX:+HeapDumpOnOutOfMemoryError -XX:HeapDumpPath=/data/im/dumps"
```

## 三、应用生产配置 (application-prod.yml 模板)

```yaml
server:
  port: ${PORT:8080}

spring:
  datasource:
    url: jdbc:mysql://${DB_HOST}:3306/im_${DB_NAME}?useUnicode=true&characterEncoding=utf8
    username: ${DB_USER}
    password: ${DB_PASS}
  redis:
    host: ${REDIS_HOST}
    port: 6379
  rabbitmq:
    host: ${MQ_HOST}
    username: ${MQ_USER}
    password: ${MQ_PASS}
  cloud:
    nacos:
      discovery:
        server-addr: ${NACOS_HOST}:8848

jwt:
  secret: ${JWT_SECRET}
  access-expire: 7200
  refresh-expire: 604800

minio:
  endpoint: http://${MINIO_HOST}:9000
  access-key: ${MINIO_ACCESS_KEY}
  secret-key: ${MINIO_SECRET_KEY}
  bucket: im-files
```

## 四、Nginx 生产配置模板

```nginx
# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name im.yourcompany.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS 配置
server {
    listen 443 ssl http2;
    server_name im.yourcompany.com;

    ssl_certificate /etc/nginx/ssl/im.yourcompany.com.crt;
    ssl_certificate_key /etc/nginx/ssl/im.yourcompany.com.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    # 前端静态资源
    root /opt/im/web/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket 代理
    location /ws {
        proxy_pass http://127.0.0.1:8080/ws;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400;
    }

    client_max_body_size 100M;

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

## 五、数据库初始化

## 六、备份策略

### 6.1 数据库备份（每日）

```bash
#!/bin/bash
BACKUP_DIR="/data/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
mysqldump -u im_user -p'${DB_PASSWORD}' im > $BACKUP_DIR/im_$DATE.sql
find $BACKUP_DIR -name "im_*.sql" -mtime +7 -delete
```

### 6.2 文件备份（每日）

```bash
rsync -avz /data/im/files/ /data/backup/files/
```

## 八、常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 数据库连接失败 | MySQL 未启动或配置错误 | 检查 MySQL 状态和 `DB_HOST` 环境变量 |
| Redis 连接失败 | Redis 未启动或密码错误 | 检查 Redis 状态和配置 |
| 前端白屏 | 构建失败或路由配置错误 | 检查构建日志和 Nginx 配置 |
| WebSocket 连接失败 | WSS 配置错误 | 检查 SSL 证书和代理配置 |
| npm install 失败 | 网络问题 | 配置 npm 镜像 `registry.npmmirror.com` |
| Maven 依赖下载慢 | 网络问题 | 配置阿里云 Maven 镜像 |
