# 14-钉钉专项微交互

> 本文档定义 DING 强提醒、@ 提及、DING 气泡等钉钉特有的微交互细节。关联模块：09-协同办公需求 §四 DING 消息、13-模块 UI 规范。

---

## 一、DING 气泡样式

| 项 | 规范 |
|----|------|
| 背景 | 线性渐变 `#FF7E06` → `#FFB84D`（**DING 气泡豁免 12-UI交互规范与红线 §14 渐变禁令**，仅 DING 消息使用） |
| 文字 | 白色、14px、粗体 |
| 圆角 | `var(--dt-radius-lg)` (12px) |
| 内边距 | 12px 16px |
| 最大宽度 | 70%（与聊天气泡一致） |
| 状态标签 | 待确认：`var(--dt-warning)` 橙色底 + 白色字；已确认：`var(--dt-bg-hover)` 灰底 + `var(--dt-text-tertiary)` 灰字；已过期：`var(--dt-danger)` 红底 |
| 回执计数 | 右下角白色半透明 "已确认 N/M" 12px |

## 二、DING 创建对话框

- **触发**: DING 面板「+」按钮 / 会话输入栏右侧「DING」图标
- **弹窗宽度**: 560px，高自适应，垂直居中
- **字段**:
  - 接收人（必填，@ 提及选择器，支持多选、群组选择）
  - 内容（必填，≤500 字，多行文本域，高 80px）
  - 提醒方式：仅应用内（固定，灰色不可修改）
  - DING 等级：NORMAL / IMPORTANT / URGENT（单选，默认 NORMAL）
  - 截止时间：datetime-local 输入，默认当前时间 +1h，最远 +72h
- **底部按钮**: [取消(gray)] [发送(brand)] 右对齐
- **校验**: 接收人为空 → 红色边框 + "请选择接收人"；内容为空 → 红色边框 + "请输入 DING 内容"

## 三、@ 提及回执

- **被 @ 消息**: 左侧 3px `var(--dt-brand)` 竖线 + 发送者名品牌蓝高亮
- **会话列表 @ 提示**: 未处理的 @ 消息 → 会话项显示红色 "@我" 角标 + 未读数叠加
- **确认动作**: 点击 DING 气泡 [确认] 按钮或点击弹窗 [确认] → im_ding_receipt 插入 → 发送方收到 ding_ack_notify 帧 → 回执计数实时更新
- **批量确认**: DING 历史面板顶部 [全部确认] 按钮（仅未确认 DING 可见一次）

**优先级规则**: 红色>橙色>灰色；同级按最后消息时间排序。
**蓝色未读前缀**: `[草稿]` 有未读时叠加蓝色未读计数气泡。

> **颜色 token 映射**: `#FF4D4F` → `var(--dt-danger)` | `#FF7D00` → `var(--dt-warning)` | `#8A9099` → `var(--dt-text-tertiary)`

## 五、应用切换器（应用 "+" 按钮）

| 属性 | 值 |
|------|-----|
| 位置 | L1 底部（头像上方），左对齐 |
| 尺寸 | 40×40px 圆形 |
| 颜色 | 红色 `#F53F3F`（`var(--dt-danger)`） |
| 圆角 | `50%`（圆形） |
| 图标 | 白色 "+" 图标 16px |
| Hover 背景 | 红色加深 `#D93636` |
| Hover 阴影 | `0 2px 8px rgba(245,63,63,0.3)` 品牌红阴影 |
| 点击行为 | 展开应用面板（应用中心/工作台快捷入口） |
| 动效 | scale(0.95) + 背景加深，150ms |

```scss
.app-toggle-btn {
  width: 40px;
  height: 40px;
  border-radius: 50%;
  background: var(--dt-danger);
  color: white;
  font-size: 16px;
  transition: all 0.15s;

  &:hover {
    background: #D93636;
    box-shadow: 0 2px 8px rgba(245,63,63,0.3);
  }
  &:active {
    transform: scale(0.95);
  }
}
```
