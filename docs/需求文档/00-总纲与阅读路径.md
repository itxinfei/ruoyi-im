## 一、项目定位

**RuoYi-IM** —— 面向企业内网私有化部署的**即时通讯与协同办公平台**，对标**钉钉 Windows 客户端**。

| 维度 | 内容 |
|------|------|
| 目标规模 | 10–500 人企业 |
| 核心 | IM 即时通讯（消息、会话、通话、搜索、收藏） |
| 外延 | 协同办公（审批、待办、日历、云盘 / 文档） |
| 平台模块 | 工作台、通讯录、邮箱、AI 助手 |
| 治理 | 管理后台（用户 / 群组 / 审计 / 配置） |
| 部署 | 内网私有化，无外网依赖 |

**产品原则**：IM 是核心中的核心，其余协同能力围绕 IM 展开；视觉与交互对齐钉钉。
