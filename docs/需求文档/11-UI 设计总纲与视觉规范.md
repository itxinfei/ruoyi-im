# 11-UI 设计总纲与视觉规范

> **定位**：PC 版钉钉视觉总纲。定义设计原则、三栏骨架策略、页面模板库、模块映射关系与跨模块统一组件契约。
> **更新时间**：2026-10-27
> **像素级细节**：见 `12-UI 交互规范与红线.md`
> **CSS 变量源**：`ruoyi-im-web/src/styles/design-tokens.scss`

## 复刻基准声明（SSOT）

> **本项目 UI 以「钉钉 Windows 桌面端 8.2.0」为复刻基准。** 所有页面布局、组件密度、交互反馈的判定标准，最终都回到"与钉钉桌面端是否一致"。

### 基准定义

| 项 | 定版 |
|----|------|
| 复刻原型 | **钉钉 Windows 桌面端 8.2.0**（PC 客户端，非移动端、非 Web 版） |
| 平台策略 | **Desktop First**，不做移动端让步；宽度不足允许横向滚动，禁止折叠三栏 |
| 判定顺序 | 骨架一致 → 视觉一致 → 交互一致 → 功能闭环（见下方 L1–L4） |
| 像素权威源 | `12-UI 交互规范与红线.md`（历史证据：`docs/历史素材/UI设计规范.md` 的 00-钉钉8.2像素级权威基线） |
| 不接受的表述 | ❌「参考钉钉风格」「大致对齐」——每条规则必须落到 Token / 组件 / CSS / 验收用例 |

### 复刻等级定义（L1–L4）

| 等级 | 含义 | 判定内容 |
|------|------|---------|
| **L1 结构一致** | 布局与模块层级与钉钉一致 | 三栏骨架、区域划分、层级关系 |
| **L2 视觉一致** | 间距、尺寸、状态色、组件密度一致 | Token 覆盖率、尺寸吻合度 |
| **L3 交互一致** | 点击、悬停、右键、空状态、失败反馈一致 | 6+1 状态、反馈时机 |
| **L4 功能闭环** | 入口真实可达，主流程与异常流程可完成 | 无死按钮、无假菜单、异常可恢复 |

**最低要求**
- **IM 主链路页面 → 必须达到 L4**
- **非 IM 页面 → 最低 L2，且关键入口必须达到 L3**

### 各类页面最低等级要求

| 页面类型 | 典型模块 | 最低等级 | 结构基线 | 验收重点 |
|---------|---------|---------|---------|---------|
| 三栏主链路页 | 消息、搜索 | **L4** | L1+L2+L3 稳定存在，详情走抽屉/弹层 | 不折叠、不漂移、主链路真实可用 |
| 列表-详情协同页 | 通讯录、云盘、待办、日历、收藏、审批 | **L3** | 左侧筛选/目录 + 主列表 + 抽屉详情 | 列表密度、筛选效率、详情不打断主任务 |
| 工作台聚合页 | 工作台 | **L3** | 入口分组清楚，信息层级稳定 | 高频入口前置，卡片不过度装饰 |
| 表单 / 流程页 | 审批发起、设置、资料编辑 | **L3** | 表单主区 + 固定操作区 + 校验反馈 | 提交路径明确，错误状态可定位 |
| 全屏协作页 | 通话 | **L4** | 主内容绝对优先，控制层克制 | 来电 / 进行中 / 最小化 / 异常态完整 |
| 详情抽屉页 | 群详情 | **L3** | 右侧滑出，不常驻第四列 | 权限隔离、滚动加载不影响主区 |
| 后台框架页 | 管理后台 | **L2** | 左菜单 + 面包屑 + 内容卡片 | 表格分页排序筛选、危险操作二次确认 |

> 新模块若未在上表列出，必须先归入某一页面类型，再定义专项验收项。

### 验收口径

1. 每个页面至少提供一组**「当前实现 vs 钉钉」对比截图**
2. 验收必须同时覆盖**视觉 / 交互 / 功能闭环**三个维度
3. 某项未达对应等级，必须在 PR 或 issue 中**写明原因**，不得静默降级
4. 验收结果回写到模块文档的状态表与任务卡 `acceptance`

### ⚠️ 明确不照搬清单（内网私有化差异）

以下钉钉功能**不纳入复刻范围**，不得因"钉钉有"而引入：

| 不照搬项 | 原因 |
|---------|------|
| 钉钉开放平台 / 应用市场 / ISV 生态入口 | 内网私有化，无开放生态 |
| 钉钉外部服务（外卖、出行、支付、钉钉文档云） | 无外网依赖 |
| 短信 / 电话外呼 DING | 决策收敛为仅应用内提醒（见 `18`） |
| 移动端布局与手势 | Desktop First |
| 钉钉账号体系 / 扫码登录 | 走内网账号体系 |

### ⚠️ 尺寸冲突裁决（以本节为准）

| 项 | 裁决 | 说明 |
|----|------|------|
| 会话列表头像 | **40×40**（`--dt-avatar-session`） | 钉钉 8.2 实测；**刻意**大于消息区头像，**禁止**为求统一改成一个尺寸 |
| 消息区头像 | **36×36**（`--dt-avatar-size-md`） | 让出空间给气泡 |
| 其他业务列表头像 | **36×36** | 通讯录成员列表、文件列表等 |
| 会话列表 / 分类导航选中指示条 | **3px** 品牌蓝 | `12` §十 曾写 4px，已作废 |
| L1 侧边栏选中项 | **白色圆角块 + 品牌蓝图标** | 蓝底白图标，选中反白；不再使用独立指示条 |
| 工作台分组标题竖线 | **4px** 品牌蓝 | — |
| 头像圆角 | **4px**（方形微圆角） | 桌面端**禁止**圆形头像（通话白名单除外） |

## 一、设计原则（五条军规）

### 1.1 Desktop First，不做移动端让步

- 页面根布局服务桌面办公场景
- 优先保证横向多栏稳定
- 宽度不足时允许横向滚动，**禁止**破坏 L1/L2/L3 层级

### 1.2 稳定骨架优先于局部炫技

- 先定义 L1/L2/L3 主骨架
- 次级信息通过抽屉/弹窗/右键菜单/Popover 暴露
- **禁止**新增常驻第四列

### 1.3 IM 是平台中心

- 消息/搜索/通话/文件/群详情 → **贴近钉钉桌面端**
- 工作台/审批/日历/待办/云盘 → 可以有业务差异，但不偏离统一语言

### 1.4 低噪音、高密度、强反馈

- 页面以留白 / 边框 / 浅底色 / 轻量 hover 区分层级
- 避免大阴影、大圆角、渐变、悬浮位移
- 列表项/工具栏/输入区 → **桌面效率优先**

### 1.5 设计必须能落到代码和验收

- 每条 UI 规则必须映射到 Token、组件、CSS 或验收用例
- 不允许只写"参考钉钉风格"

## 二、PC 页面模板库

| 模板 | 适用模块 | 结构 | 体验要点 |
|------|---------|------|---------|
| **三栏主链路** | 消息、搜索 | L1 + L2(250px) + L3 | 导航稳定、信息密度高、详情触发式展开 |
| **列表-详情协同** | 通讯录、云盘、待办、审批、日历 | L1 + 左侧筛选/目录(240px) + 主列表/视图 + 抽屉详情 | 快速筛选、批量、详情不打断主任务 |
| **工作台聚合** | 工作台首页 | L1 + 主内容分组 | 入口清晰、优先级明确、分组稳定 |
| **表单/流程** | 审批发起、设置、资料编辑 | L1 + 表单主区 + 固定操作区 | 输入效率、校验反馈、保存路径明确 |
| **全屏协作** | 音视频通话 | 全屏画布 + 轻量控制层 | 聚焦主任务、控制区克制、异常清晰 |

### 2.1 模板选择规则

- 持续沟通/筛选/查看 → **三栏主链路**或**列表-详情协同**
- 任务汇总/入口分发 → **工作台聚合**
- 结构化录入/审批提交 → **表单/流程**
- 实时音视频 → **全屏协作**

## 四、跨模块统一组件契约

### 4.1 必须统一的基础组件

| 组件 | 统一要素 |
|------|---------|
| 一级导航项 | 图标尺寸 24px / 选中态 / hover / 底部头像 |
| 列表项 | 高度 56px / padding 16px / 标题摘要层级 / 未读标签 |
| 工具栏 | 按钮 32×32 / 图标 16px / hover 浅底 |
| 抽屉 | 宽度 320px(详情) / 标题加粗 / 操作在右下 |
| 弹窗 | 居中 / 遮罩 / ESC 关闭 |
| 空状态 | 64px 图标 + 14px 文案 + 16px 间距 |

### 4.2 必须统一的状态集合

| 状态 | 说明 |
|------|------|
| 默认 | 标准展示 |
| Hover | 浅底提升 |
| Active / Selected | 品牌蓝边/背景 |
| Disabled | 灰显 |
| Loading | 骨架屏/skeleton |
| Empty | 空状态占位 |
| Error / Offline | 错误提示 + 重试 |

### 4.3 必须统一的 Token 入口

1. **优先级**：CSS 变量 > 预处理器变量 > 硬编码
2. AI 生成代码时禁止硬编码非标准蓝、非标准圆角、非栅格间距
3. 新增 Token 必须先补 `design-tokens.scss`

## 五、全局页面骨架

### 5.1 标准桌面骨架

| 层级 | 作用 | 约束 |
|------|------|------|
| L1 一级导航 | 全局模块切换 | 64px 固定，品牌蓝底 |
| L2 二级列表 | 会话/筛选/目录 | 240px（消息 250px） |
| L3 主内容 | 主任务 | flex:1，最小 480px |
| Overlay | 抽屉/弹窗 | 临时、不打断 |

### 5.2 侧边栏专属视觉

| 项 | 值 |
|----|----|
| 背景 | `#277EFB` 品牌蓝（纯色，**非**深灰/渐变） |
| 图标/文字默认 | `#FFFFFF` |
| 图标/文字激活 | `#277EFB` |
| hover | 背景 `rgba(255,255,255,0.16)`，图标/文字 `#FFFFFF` |
| 激活背景 | `#FFFFFF` 白色圆角块 |
| 选中形态 | 白色圆角块 + 品牌蓝图标（块本身即选中标识，不设独立指示条） |

### 5.3 聊天气泡视觉

| 项 | 发送方 | 接收方 |
|----|--------|--------|
| 背景 | `#277EFB` | `#FFFFFF` |
| 文字 | `#FFFFFF` | `#171A1D` |
| 圆角 | `var(--dt-radius-lg)` 12px | 同 |
| 最大宽度 | 聊天区 70% | 同 |

## 六、设计交付要求

### 6.1 每个 UI 设计任务至少产出

1. **页面定位**：属于哪个模块、模板类型
2. **结构图**：L1/L2/L3 区域划分
3. **状态清单**：6+1 态覆盖
4. **关键尺寸**：遵循 `12-UI交互规范与红线.md` §二、§四、§五
5. **交互路径**：入口→主流程→异常→返回
6. **验收点**：可检查条目（非笼统描述）

### 6.2 文档回写义务

| 变化类型 | 必须同步更新 |
|---------|-------------|
| L1 导航或路由变化 | 本文档 + `14-页面路由规范` |
| IM 页面细节变化 | `12-UI交互规南与红线.md` + `13-模块UI规范` |
| Token/色值变化 | `design-tokens.scss` |

## 七、设计完成定义（Definition of Done）

1. ✅ 页面骨架符合 PC 桌面布局，无移动端化折叠
2. ✅ 视觉与钉钉 Windows 8.2.0 一致：低噪音 / 轻阴影 / 8px 栅格 / 方形微圆角头像
3. ✅ 关键路径有真实入口和反馈，无死按钮/空白页/假菜单
4. ✅ 6+1 状态齐全（默认/Hover/Active/Loading/Empty/Error/Disabled）
5. ✅ 已补对应模块文档、验收口径和任务引用
