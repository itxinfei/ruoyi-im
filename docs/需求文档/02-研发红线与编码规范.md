# 02 研发红线与编码规范

> **定位**：面向 **JDK 25 + Spring Boot 4.1.1 + Vue 3 + TypeScript** 技术栈的**硬红线与编码规范**。所有代码、评审、CI 以此为准。
> **更新时间**：2026-10-27
> **变更性质**：随技术栈推翻重选而重写（原 Java 1.8 / JavaScript 红线作废）

---

## 一、概述

本文档分四部分红线：**后端**、**前端**、**数据与缓存**、**质量门**。违反任意一条视为不合格，评审驳回。

---

## 二、后端红线（JDK 25 + Spring Boot 4.1.1）

### 2.1 命名空间与语法

1. **必须使用 `jakarta.*` 命名空间**，禁止 `javax.*`（Spring Boot 3+ 已迁移，4 延续）。
2. 允许并使用 Java 25 现代语法：`record`、`sealed class`、虚拟线程（按需）、局部变量 `var`。
3. 禁止 Java 8 时代遗留写法（如匿名内部类代替 Lambda）。
4. 禁止随意返回 `null`（用明确语义、空对象或谨慎使用 `Optional`）。

### 2.2 分层与调用方向

5. 严格 `Controller → Service → Mapper` **单向调用**，禁止反向依赖。
6. Controller **不得直接调用 Mapper**。
7. **DTO / VO 隔离**：Controller 只接收 DTO、返回 VO，**禁止直接暴露数据库 Entity**。

### 2.3 事务与异常

8. `@Transactional` 必须标注在**公共方法**上；禁止同类内部自调用导致事务失效；禁止大事务包裹远程调用 / 文件 IO。
9. 统一异常处理：**禁止把异常堆栈直接返回前端**，敏感信息必须脱敏。

### 2.4 日志与安全

10. 统一使用 **SLF4J**，禁止 `System.out.println`。
11. 所有接口必须做**权限校验**（RBAC），禁止"能访问就能改"。
12. 输出内容必须 **XSS 过滤**；SQL 必须参数化（禁止拼接）；敏感词必须过滤。

### 2.5 缓存（Redis 7）

13. 所有缓存 key 必须设 **TTL**，禁止无过期缓存。
14. 禁止 `KEYS *` 等阻塞命令；禁止大 key（如超 1MB）。
15. 缓存与 DB 一致性：更新采用"先更 DB，再删缓存"或事件驱动失效。

### 2.6 ORM（MyBatis Plus）

16. 查询优先 **Lambda 条件构造器**；禁止循环查库（防 N+1）；批量操作用批量 API。
17. 主键统一**雪花算法**，禁止自增。

---

## 三、前端红线（Vue 3 + TypeScript）

18. 组件统一 `<script setup lang="ts">`，组合式 API。
19. **禁止 `any` 泛滥**；`props` / `emits` 必须类型化；接口返回值定义 `interface`。
20. **图标 / 字体 / 图片仅本地资源，禁止外部 CDN**（内网气密性）。
21. 状态管理统一 **Vuex 4**。
22. 样式：颜色 / 间距 / 圆角 / 字号统一走 **CSS 变量 Design Tokens**，**禁止硬编码**。
23. 长列表必须虚拟滚动；图片懒加载；避免大组件全量重渲染。
24. 所有用户输入渲染前必须 **dompurify 过滤**。

---

## 四、数据与缓存红线

25. **MySQL 8.0**，字符集 **utf8mb4_unicode_ci**。
26. 主键雪花算法；禁用数据库外键，采用逻辑关联；重要数据软删除。
27. **Redis 7.x**：在线状态、会话缓存、限流、幂等；key 命名统一前缀 `im:`。
28. 高频查询字段必须建索引；禁止 `SELECT *`。

---

## 五、质量门与提交协议

| 门控 | 要求 |
|------|------|
| 构建 | 前端 `npm run build` 通过；后端 `mvn clean package` 通过 |
| 静态检查 | ESLint / P3C 无阻断项；Prettier 格式化 |
| 测试 | 单元测试覆盖率 **≥ 80%**（行 / 分支） |
| 契约 | 接口字段与 `05-RESTful API 规范.md` 一致，禁止脑补 |
| 提交 | commit message 中文，格式 `type: 简述`（feat/fix/refactor/docs/chore） |

**HALT 条件**（出现即停止执行并上报）：

- 需求文档未定义所需接口 / 字段
- 文档与代码冲突且无法判定以谁为准
- 需要执行公网 / 生产环境写操作
