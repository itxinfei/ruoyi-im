### 1.2 数据结构设计

| Key 模式 | 类型 | 用途 | TTL |
|----------|------|------|-----|
| `online:{userId}` | String | 用户在线状态 (值=serverId) | 心跳续期 5min |
| `ws:node:{userId}` | String | userId 所在 WS 节点 | WS 断开清除 |
| `session:lastRead:{sessionId}:{userId}` | String | 会话最后已读 seq | 永不过期 |
| `msg:pending:{userId}:{msgId}` | String | 待确认消息 (值=JSON) | 30min |
| `history:{sessionId}` | List | 会话最近 N 条消息缓存 | LRU 淘汰 |
| `offline:{userId}` | List | 用户离线期间收到的消息 | 到线消费后清除 |
| `refresh:{userId}` | String | Refresh Token | 7d |
| `blacklist:{jti}` | String | 吊销的 Token | 与 Token exp 一致 |
| `lock:{resource}` | String | 分布式锁 | 30s |
| `snowflake:lock:{datacenterId}` | String | 雪花 ID 数据中心锁 | 1s |
| `rate:{userId}:{action}` | String | API 限流计数 | 60s |
| `group:info:{groupId}` | Hash | 群组基本信息缓存 | 变更清除 |
| `user:profile:{userId}` | Hash | 用户资料信息缓存 | 变更清除 |

### 1.3 Spring Data Redis 配置

```java
@Configuration
@EnableCaching
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory cf) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(cf);
        GenericJackson2JsonRedisSerializer ser = new GenericJackson2JsonRedisSerializer();
        StringRedisSerializer strSer = new StringRedisSerializer();
        template.setKeySerializer(strSer);
        template.setValueSerializer(ser);
        template.setHashKeySerializer(strSer);
        template.setHashValueSerializer(ser);
        return template;
    }

    @Bean
    public CacheManager cacheManager(RedisConnectionFactory cf) {
        RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofMinutes(10))
            .serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
            .serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(new GenericJackson2JsonRedisSerializer()));
        return RedisCacheManager.builder(cf).cacheDefaults(config).build();
    }
}
```

### 1.4 Pub/Sub 跨节点广播

```java
// WS 节点间消息广播
@Component
public class RedisWsBroadcast {
    @Autowired private RedisTemplate<String, Object> redis;
    @Autowired private ObjectMapper objectMapper;

    public void publishMessage(Long targetUserId, ServerSentEvent event) {
        String channel = "ws:broadcast:user:" + targetUserId;
        redis.convertAndSend(channel, JSON.toJSONString(event));
    }

    @RedisListener(topic = "ws:broadcast:user:*")
    public void onBroadcast(String channel, String payload) {
        ServerSentEvent event = objectMapper.readValue(payload, ServerSentEvent.class);
        // 推送给本地持有该 userId 连接的会话
        connectionManager.pushToLocalUser(event.getTargetUserId(), event);
    }
}
```

## 二、RabbitMQ

### 2.1 Exchange & Queue 命名

| Exchange | 类型 | 绑定的 Queue | 用途 |
|----------|------|-------------|------|
| `im.msg` | Topic | `im.msg.store` | 异步落库 |
| | | `im.msg.push` | 离线推送 |
| `im.event` | Fanout | `im.event.presence` | 在线状态广播 |
| | | `im.event.audit` | 审计日志采集 |
| `im.delay` | x-delayed-message | `im.delay.offline-push` | 离线推送延迟 |
| `im.dlx` | Topic | `im.dlq.msg` | 死信队列(3 次重试) |

### 2.3 Spring AMQP 配置

```java
@Configuration
public class RabbitConfig {

    @Bean
    public TopicExchange msgExchange() {
        return new TopicExchange("im.msg", true, false);
    }

    @Bean
    public FanoutExchange eventExchange() {
        return new FanoutExchange("im.event", true, false);
    }

    @Bean
    public Queue msgStoreQueue() {
        return QueueBuilder.durable("im.msg.store")
            .withArgument("x-dead-letter-exchange", "")
            .withArgument("x-dead-letter-routing-key", "im.dlq.msg")
            .build();
    }

    @Bean
    public Binding msgStoreBinding(Queue msgStoreQueue, TopicExchange msgExchange) {
        return BindingBuilder.bind(msgStoreQueue).to(msgExchange).with("msg.store");
    }

    @RabbitListener(queues = "im.msg.store", containerFactory = "batchListenerFactory")
    public void handleMessageStore(List<MessageStoreEvent> events) {
        messageStoreService.batchStore(events);
    }
}
```

### 2.4 消息可靠性保障

| 机制 | 实现 |
|------|------|
| 生产者确认 | publisher-returns + publisher-confirm-type=correlated |
| 消费者手动 ACK | acknowledge-mode=manual，落库成功才 ACK |
| 失败重试 | 3 次指数退避，仍失败 → DLQ |
| 幂等消费 | 业务的唯一键去重 (messageId) |
| DLQ 监控 | DLQ 有消息触发告警 |

```java
@Configuration
@ConfigurationProperties(prefix = "minio")
public class MinioConfig {
    private String endpoint;
    private String accessKey;
    private String secretKey;

    @Bean
    public MinioClient minioClient() {
        return MinioClient.builder()
            .endpoint(endpoint)
            .credentials(accessKey, secretKey)
            .build();
    }
}

// 文件上传
@Service
public class FileService {
    @Autowired private MinioClient minioClient;

    public String uploadFile(String bucket, MultipartFile file) {
        String objectName = IdWorker.getIdStr() + "_" + file.getOriginalFilename();
        minioClient.putObject(PutObjectArgs.builder()
            .bucket(bucket)
            .object(objectName)
            .stream(file.getInputStream(), file.getSize(), -1)
            .contentType(file.getContentType())
            .build());
        return objectName;
    }

    public String getPresignedUrl(String bucket, String objectName, int expirySeconds) {
        return minioClient.getPresignedObjectUrl(GetPresignedObjectUrlArgs.builder()
            .method(Method.GET)
            .bucket(bucket)
            .object(objectName)
            .expiry(expirySeconds)
            .build());
    }
}
```

## 五、LiveKit (视频通话)

### 5.1 集成方式

```java
// 服务端: 生成 Connect Token
@Service
public class CallService {
    @Value("${livekit.api-key}")  private String apiKey;
    @Value("${livekit.api-secret}") private String apiSecret;
    @Value("${livekit.url}")       private String serverUrl;

    public String createCallToken(String roomName, Long userId) {
        AccessToken token = new AccessToken(apiKey, apiSecret);
        token.setIdentity(userId.toString());
        token.setTtl(3600); // 1 小时
        VideoGrant grant = new VideoGrant();
        grant.setRoomJoin(true);
        grant.setRoom(roomName);
        grant.setCanPublish(true);
        grant.setCanSubscribe(true);
        token.addGrant(grant);
        return token.toJwt();
    }
}

// 前端调用
async function startCall(roomId: string, token: string) {
    const room = new Room({
        adaptiveStream: true,
        dynacast: true,
        videoCaptureDefaults: { resolution: VideoPreset.h720fps15.resolution }
    });
    await room.connect(serverUrl, token);
    await room.localParticipant.enableCameraAndMicrophone();
}
```

### 6.4 搜索 SQL 示例

```sql
-- 会话内搜索 (ngram 分词 + 自然语言模式)
SELECT msg_id, conv_id, sender_id, msg_type, content, server_seq, send_time,
       MATCH(content) AGAINST(? IN NATURAL LANGUAGE MODE) AS relevance
FROM im_message
WHERE conv_id = ?
  AND MATCH(content) AGAINST(? IN NATURAL LANGUAGE MODE)
  AND deleted = 0
ORDER BY relevance DESC, server_seq DESC
LIMIT 20;

-- 全局搜索 (仅搜索用户有权限的会话)
SELECT m.msg_id, m.conv_id, m.sender_id, m.msg_type, m.content, m.send_time,
       MATCH(m.content) AGAINST(? IN NATURAL LANGUAGE MODE) AS relevance
FROM im_message m
JOIN im_session_member sm ON m.conv_id = sm.conv_id
WHERE sm.user_id = ?
  AND MATCH(m.content) AGAINST(? IN NATURAL LANGUAGE MODE)
  AND m.deleted = 0
ORDER BY m.send_time DESC
LIMIT 50;
```

## 七、ONLYOFFICE 文档协同

### 7.1 集成架构

```text
Browser
   │  ONLYOFFICE JS API
   ▼
ONLYOFFICE Document Server (:80)
   │  回调 (save)
   ▼
im-collab (Spring Boot)
   │  存储
   ▼
im_doc 数据库 + MinIO 文件存储
```

### 7.2 文档打开流程

```text
1. 前端请求 /im/doc/office/edit/{docId}
2. im-collab 组装 Document Server 配置:
   {
     "document": {
       "fileType": "docx",
       "key": "unique-cache-key",
       "title": "文档标题",
       "url": "minio-presigned-download-url"
     },
     "editorConfig": {
       "callbackUrl": "https://im-server/im/doc/office/callback",
       "user": {"id":"112","name":"张三"},
       "mode": "edit"
     },
     "token": "<JWT-signed-config>"
   }
3. 前端初始化 ONLYOFFICE editor
4. 编辑中 ONLYOFFICE Server 调 callbackUrl 通知保存
5. im-collab 用 presigned PUT URL 上传回 MinIO
```

### 7.3 文档协作回调处理

```java
@PostMapping("/im/doc/office/callback")
public ResponseEntity<Void> officeCallback(@RequestBody OfficeCallbackRequest cb) {
    if (cb.getStatus() == 2) { // 文档已准备好保存
        String fileUrl = cb.getUrl();
        String docKey = cb.getKey();
        // 从 fileUrl 下载更新后的文件到 MinIO
        collabDocService.saveDocumentContent(docKey, fileUrl);
    } else if (cb.getStatus() == 6) { // 文档强制保存 (断网恢复后)
        collabDocService.saveDocumentContent(cb.getKey(), cb.getUrl());
    }
    return ResponseEntity.ok(null);
}
```
