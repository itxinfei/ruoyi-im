## 一、系统上下文图

### 1.1 外部参与者

| 参与者 | 类型 | 接入方式 |
|--------|------|---------|
| 桌面用户 | 人 | Electron 桌面客户端 (Windows/macOS/Linux) |
| Web 用户 | 人 | 浏览器 Web SPA |
| 移动用户 | 人 | H5 浏览器（二期预留原生 App） |
| 企业管理员 | 人 | 管理后台 Web |

```text
┌───────────────────────── 内网部署域 ─────────────────────────┐
│                                                              │
│  [用户] ──> [CDN/Nginx] ──> [12 个微服务] ──> [数据层]       │
```

### 3.2 分层部署模式 (Prod)

```text
┐
│  [接入层 - 1 台]                                │
│  Nginx + WSS Gateway (4C8G)                    │
├─────────────────────────────────────────────────┤
│  [应用层 - 2~3 台]                              │
│  全部 12 个微服务 (每台 8C16G 承载全量副本)     │
├─────────────────────────────────────────────────┤
│  [中间件层 - 1 台]                              │
│  Nacos + Redis 主从 + RabbitMQ (8C16G)         │
├─────────────────────────────────────────────────┤
│  [数据层 - 1 台]                                │
│  MySQL 主从 + MinIO (16C32G + 1TB SSD)        │
├─────────────────────────────────────────────────┤
│  [媒体层 - 1 台]                                │
│  LiveKit + ONLYOFFICE (8C16G)                  │
└─────────────────────────────────────────────────┘
```

## 四、环境分层

| 环境 | 编排方式 | 用途 | 数据 |

## 五、CI/CD 流水线

### 5.1 流水线阶段

```text
代码提交 (push / merge to develop)
    │
    ▼
[ Stage 1: Lint + Test ] ─────────────────────────── 3 min
    ├── Frontend: eslint + vitest (unit)
    └── Backend: mvn test (JUnit 5)
    │
    ▼
[ Stage 2: Build ] ───────────────────────────────── 5 min
    ├── Frontend: vite build → dist/ + electron-builder
    └── Backend: mvn package → target/*.jar
    │
    ▼
[ Stage 3: Docker Build ] ────────────────────────── 5 min
    └── docker build -t harbor.internal.com/im-{svc}:{VERSION}
    │
    ▼
[ Stage 4: Push to Harbor ] ──────────────────────── 2 min
    └── docker push harbor.internal.com/im-{svc}:{VERSION}
    │
    ▼
[ Stage 5: Deploy to Test ] ──────────────────────── auto
    └── docker-compose up -d (test server)
    │
    ▼
[ Stage 6: E2E Test ] ────────────────────────────── 10 min
    └── playwright (critical flows: login/send/recv/call)
    │
    ▼
[ Gate: Manual Approval ] ────────────────────────── prod
    │
    ▼
[ Stage 7: Deploy to Prod ] ──────────────────────── blue-green
    └── docker-compose up -d (prod server)
```

### 5.2 镜像版本策略

| 分支 | Tag 格式 | 示例 |
|------|---------|------|
| develop | develop-{sha:7} | develop-a1b2c3d |
| release/* | rc-{version} | rc-1.0.0 |
| main | {version} | 1.0.0 |
| main | latest | latest |

## 六、监控与告警

| 层级 | 工具 | 监控项 |
|------|------|--------|
| 基础设施 | Prometheus + Node Exporter | CPU/内存/磁盘/网络 |
| 容器 | cAdvisor + Prometheus | 容器资源使用率 |
| 应用 | Micrometer + Prometheus | QPS/延迟/错误率/JVM |
| 日志 | Loki (或 ELK) | 结构化日志聚合 |
| 链路 | SkyWalking | 分布式调用链追踪 |
| 健康 | Kubernetes / Docker healthcheck | 服务存活状态 |
| 告警 | AlertManager → 邮件/企业微信 | 阈值告警与自愈 |
