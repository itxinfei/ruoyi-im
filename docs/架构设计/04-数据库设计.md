# 04 数据库设计

> **定位**：定义 9 个分库、44 张核心表的完整结构 SQL、索引、约束。
> **更新时间**：2026-10-30
> **通用规则**：雪花主键、utf8mb4、软删除(delFlag)、create_time/update_time

---

## 一、分库策略

| 数据库 | 服务 | 核心表数 | 说明 |
|--------|------|---------|------|
| im_msg | im-message | 7 | 消息核心表 + 反应 + 已读 + 编辑历史 + 收藏 + DING |
| im_sess | im-session | 4 | 会话 + 成员 + 草稿 + 分组 |
| im_grp | im-group | 4 | 群组 + 成员 + 公告 + 群文件 |
| im_collab | collab-task | 6 | 待办 + 审批 + 审批节点 + 工作报告 + 审批模板 + 工作台日程 |
| im_calendar | collab-calendar | 4 | 日程事件 + 提醒 + 参与者 + 重复事件实例 |
| im_doc | collab-doc | 4 | 文档 + 版本 + 协作者 + 分享 |
| im_file | file-storage | 3 | 文件资产 + 分片上传 + 云盘文件 |
| im_user | platform-user | 5 | 用户 + 部门 + 部门成员 + 好友 + 好友请求 |
| im_admin | admin-system | 3 | 审计日志 + 系统配置 + 后台账号 |

## 二、DDL 建表脚本

### 2.1 im_msg 库（消息服务）

```sql
-- ============================================
-- 数据库: im_msg (消息服务)
-- 字符集: utf8mb4 / utf8mb4_unicode_ci
-- 主键策略: 雪花算法 (ASSIGN_ID)
-- ============================================

CREATE DATABASE IF NOT EXISTS im_msg DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE im_msg;

-- 会话表 (同时维护 lastMsg + serverSeq 游标)
CREATE TABLE im_message (
    id              BIGINT          NOT NULL COMMENT '雪花ID',
    conversation_id BIGINT          NOT NULL COMMENT '会话ID',
    sender_id       BIGINT          NOT NULL COMMENT '发送者ID',
    msg_type        VARCHAR(20)     NOT NULL COMMENT 'TEXT/IMAGE/FILE/VOICE/VIDEO/LINK/LOCATION/GEOTAG/DING/SYSTEM/RECALL',
    content         TEXT            NULL COMMENT '消息内容(TEXT存文本, 其他存JSON)',
    extra           JSON            NULL COMMENT '扩展字段(图片宽高/文件信息/语音波形等)',
    status          TINYINT         NOT NULL DEFAULT 0 COMMENT '0=PENDING 1=SENDING 2=SENT 3=DELIVERED 4=FAILED 9=RECALLED',
    server_seq      BIGINT          NOT NULL COMMENT '会话内服务端序号(排序用)',
    client_seq      VARCHAR(64)     NOT NULL COMMENT '客户端序号(幂等去重)',
    recall_time     DATETIME        NULL COMMENT '撤回时间',
    deleted         TINYINT         NOT NULL DEFAULT 0 COMMENT '0=正常 1=已删除',
    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_client_seq (conversation_id, client_seq),
    KEY idx_conv_seq (conversation_id, server_seq),
    KEY idx_sender (sender_id, create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='消息主表';

-- 消息表情反应表
CREATE TABLE im_message_reaction (
    id          BIGINT      NOT NULL,
    message_id  BIGINT      NOT NULL,
    emoji       VARCHAR(32) NOT NULL,
    user_id     BIGINT      NOT NULL,
    create_time DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_reaction (message_id, emoji, user_id),
    KEY idx_message (message_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='消息表情反应';

-- 消息已读记录表
CREATE TABLE im_message_read (
    id          BIGINT      NOT NULL,
    message_id  BIGINT      NOT NULL,
    user_id     BIGINT      NOT NULL,
    read_time   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_read (message_id, user_id),
    KEY idx_user_read (user_id, read_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='消息已读记录';

-- 消息编辑历史表
CREATE TABLE im_message_edit_history (
    id          BIGINT      NOT NULL,
    message_id  BIGINT      NOT NULL,
    old_content TEXT        NOT NULL,
    new_content TEXT        NOT NULL,
    edit_time   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_message (message_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='消息编辑历史';

-- 离线消息队列（用于用户不在线时暂存）
CREATE TABLE im_offline_message (
    id              BIGINT      NOT NULL,
    user_id         BIGINT      NOT NULL COMMENT '目标用户',
    message_id      BIGINT      NOT NULL,
    status          TINYINT     NOT NULL DEFAULT 0 COMMENT '0=待投递 1=已投递',
    create_time     DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    delivered_time  DATETIME    NULL,
    PRIMARY KEY (id),
    KEY idx_user_status (user_id, status, create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='离线消息队列';
```

-- 消息收藏表 (IM-S-001~005)

    ding_level      VARCHAR(10)     NOT NULL DEFAULT 'NORMAL' COMMENT 'NORMAL/IMPORTANT/URGENT',

    PRIMARY KEY (id),
    KEY idx_msg (msg_id),

-- 消息@提及关联表 (IM-D-011)

### 2.2 im_sess 库（会话服务）

```sql
CREATE DATABASE IF NOT EXISTS im_sess DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE im_sess;

-- 会话表
CREATE TABLE im_session (
    id              BIGINT          NOT NULL,
    session_type    TINYINT         NOT NULL COMMENT '1=单聊 2=群聊 3=机器人',
    creator_id      BIGINT          NOT NULL,
    last_message_id BIGINT          NULL,
    last_msg_time   DATETIME        NULL,
    last_server_seq BIGINT          NOT NULL DEFAULT 0 COMMENT '最后消息序号(游标)',

    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,

    KEY idx_creator (creator_id, last_msg_time DESC),
    KEY idx_last_msg (last_msg_time DESC)
```

## 三、Redis 缓存模型

| 用途 | Key 模式 | TTL | 说明 |
|------|---------|-----|------|
| 在线状态 | `im:online:{userId}` | 60s（心跳续期） | 值为 serverId，WS 路由用 |
| 会话未读数 | `im:unread:{userId}:{convId}` | 永久（已读删除） | Integer 计数 |
| 发送幂等 | `im:idempotent:{clientSeq}` | 24h | String SETNX |
| 限流 | `im:rate:{userId}:{action}` | 60s | Integer 递增 |
| Token 黑名单 | `im:token:blacklist:{jti}` | 7d | String |
| 序号发生器 | `im:seq:{convId}` | 永久 | Long INCR（生成 serverSeq） |
| WS 跨节点 | `ws:user:{userId}` | - | Pub/Sub Channel |
| WS 群广播 | `ws:group:{groupId}` | - | Pub/Sub Channel |
| 会话信息缓存 | `im:session:{convId}` | 24h | Hash |
| 用户信息缓存 | `im:user:{userId}` | 2h | Hash |
