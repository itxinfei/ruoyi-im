# 29 DingTalk 8.2 像素级权威基线

> **本文件是从旧 docs/00-钉钉8.2像素级权威基线.md 提取的权威颜色/字号/间距参考**。
> **定位**: 当其他文档与本文件冲突时，以本文件为准。
> **维护**: 修改本文件需附钉钉 8.2 真实截图证据。

---

## 一、颜色规范（11 种核心色）

### 主色板

| 名称 | 十六进制 | 用途 |
|------|---------|------|
| 品牌蓝 | `#277EFB` | 主操作、链接、边框选中、徽章 |
| 成功绿 | `#00B42A` | 正向提示、在线状态 |
| 警告橙 | `#FF7D00` | 提醒、DING 相关 |
| 危险红 | `#F53F3F` | 错误、离线、验证失败 |

### 文本色阶

| 名称 | 十六进制 | 用途 |
|------|---------|------|
| 文本主色 | `#171A1D` | 标题、正文 |
| 文本次色 | `#5F6670` | 副标题、辅助说明 |
| 文本三级 | `#8A9099` | 占位符、时间戳、图标按钮 |
| 文本四级 | `#C9CDD4` | 禁用文字、极弱提示 |

### 背景色阶

| 名称 | 十六进制 | 用途 |
|------|---------|------|
| 页面底色 | `#F5F6F7` | body 背景 |
| 卡片/内容白 | `#FFFFFF` | 卡片、面板、弹窗 |
| 会话列表白 | `#FFFFFF` | 会话列表区域 |
| 侧边栏背景 | `#277EFB` | 左侧 L1 导航栏（品牌蓝底 + 白色图标，选中白色圆角块） |
| 悬停灰 | `#E5E6EB` | 列表项 hover |
| 品牌浅蓝背景 | `#E6F2FF` | 按钮/标签浅底（激活态见 `--dt-bg-session-active`） |

## 二、圆角规范

| token | 值 | 用途 |
|-------|-----|------|
| `--dt-radius-xs` | `3px` | 标签、小角标 |
| `--dt-radius-sm` | `4px` | 头像、小按钮、输入框 |
| `--dt-radius-md` | `6px` | 按钮、卡片 |
| `--dt-radius-lg` | `8px` | 弹窗、聊天气泡（尖角 8/4/8/8） |
| `--dt-radius-xl` | `12px` | 抽屉、工作台应用图标 |
| `--dt-radius-2xl` | `16px` | 大弹窗 |

## 三、字号规范

| token | 值 | 用途 |
|-------|-----|------|
| `--dt-font-size-xs` | `11px` | 角标、极小文字 |
| `--dt-font-size-sm` | `12px` | 时间戳、标签、次内容 |
| `--dt-font-size-base` | `14px` | 正文、列表主文字 |
| `--dt-font-size-lg` | `16px` | 面板标题、强调文字 |
| `--dt-font-size-xl` | `17px` | 模块大标题 |

## 四、间距规范（8pt 栅格）

| token | 值 | 用途 |
|-------|-----|------|
| `--dt-spacing-xs` | `4px` | 原子级间距 |
| `--dt-spacing-sm` | `8px` | 组件内间距 |
| `--dt-spacing-md` | `12px` | 小组件间间距 |
| `--dt-spacing-base` | `16px` | 标准卡片间距 |
| `--dt-spacing-lg` | `24px` | 大区块间距 |
| `--dt-spacing-xl` | `32px` | 页面级分区间距 |

## 五、聊天气泡尖角规则（钉钉 8.2 标志）

```scss
// 发送方：右上角 4px 尖角（视觉上"戳向"接收方）
.message.is-own .chat-bubble {
  border-radius: 8px 4px 8px 8px;
  background: #95EC69;  // 钉钉发送方气泡绿底
}

// 接收方：左上角 4px 尖角
.message:not(.is-own) .chat-bubble {
  border-radius: 4px 8px 8px 8px;
  background: #FFFFFF;  // 接收方白底
}
```
